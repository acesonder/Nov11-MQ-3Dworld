# Quick Start Guide

Get started with MQ3D Virtual Hangout in 5 minutes!

## Prerequisites

- Meta Quest 3 VR headset
- Unity 2022.3.10f1 or later
- Meta Quest Developer Hub (optional)

## Quick Setup

### 1. Clone the Repository (1 minute)

```bash
git clone https://github.com/acesonder/Nov11-MQ-3Dworld.git
cd Nov11-MQ-3Dworld
```

### 2. Open in Unity (2 minutes)

1. Open Unity Hub
2. Click "Add" → Select the cloned folder
3. Open with Unity 2022.3.10f1
4. Wait for packages to import

### 3. Enable Developer Mode on Quest 3 (1 minute)

1. Open Meta Quest mobile app
2. Go to Menu → Devices → Your Quest 3
3. Enable "Developer Mode"
4. Accept USB debugging when connecting to PC

### 4. Build and Run (1 minute)

1. Connect Quest 3 via USB-C
2. In Unity: File → Build Settings
3. Click "Build and Run"
4. Put on your headset and enjoy!

## First Steps in VR

### 1. Main Menu
- Look at the floating menu in front of you
- Point with your controller and press trigger to select

### 2. Capture a Room
- Select "Room Capture" from the menu
- Press A button to start scanning
- Walk around your space
- Press A again to stop and save

### 3. Try Drawing
- Select "Drawing Mode" from the menu
- Hold the right trigger to draw in 3D space
- Use X button to undo
- Change colors and sizes in the menu

### 4. Import a 3D Model
- Select "Model Library" from the menu
- Choose "Import Model"
- Select a .fbx or .obj file
- Point and press trigger to place it

### 5. Explore Shared Worlds
- Select "World Browser" from the menu
- Browse available worlds
- Select one to load and explore

## Controls Cheat Sheet

### Right Controller
- **Trigger**: Draw / Select / Confirm
- **Grip**: Grab / Scale objects
- **A Button**: Menu / Confirm
- **B Button**: Cancel / Back
- **Thumbstick**: Move forward/backward

### Left Controller
- **Trigger**: Alternative select
- **Grip**: Grab / Rotate objects
- **X Button**: Undo
- **Y Button**: Toggle UI
- **Thumbstick**: Strafe left/right

## Troubleshooting

### App won't build?
```bash
# Clear the Library folder
rm -rf Library
# Reopen Unity
```

### Controllers not working?
- Check XR Interaction Toolkit is installed
- Restart the application
- Re-pair controllers in Quest settings

### Poor performance?
- Reduce quality settings in menu
- Close background apps on Quest
- Limit number of objects in scene
